# Декартово дерево и неявное декартово дерево

В проекте уже есть публичные интерфейсы и тесты. Нужно дописать только два файла:

- `src/cartesian_tree.cpp` — множество целых чисел на декартовом дереве;
- `src/implicit_cartesian_tree.cpp` — последовательность на неявном декартовом дереве.

Заголовочные файлы в `include/` и тесты менять не нужно.

## Сборка и запуск

```bash
cmake -S . -B build
cmake --build build
ctest --test-dir build --output-on-failure
```

Для поиска ошибок при работе с памятью:

```bash
cmake -S . -B build-asan -DENABLE_SANITIZERS=ON
cmake --build build-asan
ctest --test-dir build-asan --output-on-failure
```

## Часть 1. Обычное декартово дерево

Вершина хранит ключ и случайный приоритет. По ключам дерево является бинарным деревом поиска, а по приоритетам — кучей с максимумом в корне.

Рекомендуемый порядок работы:

1. `contains`, `collect_values`, `destroy`;
2. `split` и `merge`;
3. `insert`;
4. `erase`;
5. публичные методы `values` и `clear`.

Повторная вставка существующего ключа ничего не меняет. Удаление отсутствующего ключа также ничего не меняет.

## Часть 2. Неявное декартово дерево

Ключ не хранится: позиция элемента определяется размером левого поддерева. Каждая вершина дополнительно хранит размер поддерева и сумму его значений.

Все отрезки полуинтервальные: `[left, right)`. Например, `[1, 4)` содержит индексы `1`, `2`, `3`. Пустой отрезок разрешён.

Рекомендуемый порядок работы:

1. `node_size`, `node_sum`, `update`, `destroy`;
2. `split` по числу элементов и `merge`;
3. `insert`, `erase`, `at`;
4. `range_sum`;
5. ленивый флаг `reversed`, функции `push` и `reverse`.

Ошибочный индекс или граница отрезка должны приводить к `std::out_of_range`. Точные контракты перечислены в заголовочном файле и проверяются тестами.
